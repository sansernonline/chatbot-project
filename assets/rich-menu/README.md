# Rich Menu — X Fitness LINE OA

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `rich-menu.png` | รูปที่อัปโหลดขึ้น LINE (2500×1686 แบบใหญ่ 6 ช่อง, ~380 KB) |
| `rich-menu.jpg` | ตัวสำรอง ถ้าระบบไม่รับ PNG |
| `rich-menu.json` | กำหนดพื้นที่กดและข้อความที่ส่งเข้าแชต สำหรับ Messaging API |
| `rich-menu.html` | ต้นฉบับดีไซน์ ใช้ภาษาภาพเดียวกับเว็บ (มุมเหลี่ยม · มุมตัด · แถบแดงเอียง) แก้ข้อความหรือสีที่นี่ |
| `render.py` | สร้าง PNG/JPG ใหม่จาก HTML — `python render.py` (ต้องมี Playwright) |

## ปุ่ม

| ช่อง | ปุ่ม | ข้อความที่ส่งให้บอต |
|---|---|---|
| 01 | แพ็กเกจ & ราคา | แพ็กเกจและราคา |
| 02 | ตารางคลาส | ตารางคลาส |
| 03 | โปรโมชัน (ปุ่มหลัก สีแดง) | โปรโมชันตอนนี้มีอะไรบ้าง |
| 04 | ส่งสลิปชำระเงิน | ส่งสลิปชำระเงิน |
| 05 | ข้อมูลสมาชิก | ขอดูข้อมูลสมาชิกของฉัน |
| 06 | คุยกับพนักงาน | คุยกับพนักงาน |

## วิธีขึ้นระบบ — LINE OA Manager

1. เข้า [manager.line.biz](https://manager.line.biz) → เลือกบัญชี X Fitness
2. เมนูซ้าย **หน้าหลัก → ริชเมนู (Rich menus) → สร้าง**
3. **ตั้งค่าพื้นฐาน** — ชื่อ: `X Fitness main menu` · ช่วงเวลาแสดง: วันนี้ถึงวันที่ต้องการ · ข้อความแถบเมนู: `เมนู X Fitness` · แสดงเมนูอัตโนมัติ: เปิด
4. **เลือกเทมเพลต** → แบบ **ใหญ่ 6 ช่อง (3×2)**
5. **อัปโหลดรูปพื้นหลัง** → `rich-menu.png`
6. **การดำเนินการ** — ตั้งช่อง A–F เป็นประเภท **ข้อความ (Text)** ตามคอลัมน์ "ข้อความที่ส่งให้บอต" ในตารางด้านบน (A = 01 … F = 06 เรียงซ้าย→ขวา บน→ล่าง)
7. **บันทึก** → เปิดแชต OA ในมือถือ ลองกดครบ 6 ปุ่ม

> ตั้งผ่าน LINE OA Manager อย่างเดียว — ถ้าเคยตั้ง rich menu ผ่าน Messaging API ไว้ ต้องลบออกก่อน เพราะเมนูจาก API จะแสดงทับเมนูจาก Manager
> ไม่ได้ใช้ `rich-menu.json` ในทางนี้ (เก็บไว้เผื่อย้ายไปตั้งผ่าน API ภายหลัง)
