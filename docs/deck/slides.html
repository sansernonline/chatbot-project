ข้อความจาก LINE เดินทางยังไง

  1. LINE ส่ง webhook มาที่ /api/line/webhook โค้ดตรวจลายเซ็น HMAC ก่อน ถ้าไม่ตรงตอบ 401
  2. ตอบ 200 ทันที แล้วทำงานต่อเบื้องหลัง ไม่ให้ LINE รอ
  3. ข้อความเข้า chat.answer() ตัวเดียวกับหน้าเว็บ ส่วนภาพ ดาวน์โหลดจาก LINE แล้วส่งให้ read_image() ระหว่างนั้นขึ้นจุด "กำลังพิมพ์"
  4. ปุ่มตอบด่วน เช่น แต้มของฉัน ส่งเป็น quick reply ของ LINE
  5. ยืนยันสมาชิกแล้วจำไว้ต่อแชต LINE นั้น · จำกัด 30 ข้อความ/นาที/คน
  6. ถ้าพนักงานรับเรื่องอยู่ บอทเงียบ พนักงานตอบจากหลังบ้านผ่าน push
