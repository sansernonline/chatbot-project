## ถ้าขยายเป็น 5 นาที (เมื่ออาจารย์อนุญาต)

| เพิ่ม | เวลา | สาธิต |
|---|---|---|
| ภาพอื่น | +0:25 | ผลวัดร่างกาย (สรุปตัวเลข แนะนำคลาส ไม่ประเมินทางการแพทย์) · โปสเตอร์ MID2 (บอกว่าหมดเขต แนะนำ YEAR13) |
| LINE OA | +0:25 | ถามคำถามเดิมใน LINE ได้คำตอบเดียวกัน · แชต LINE ขึ้นในหลังบ้าน |
| สถานะ error | +0:10 | ตั้งค่าในแชต → จำลองเครือข่ายล่ม → เห็นข้อความ error และปุ่มลองอีกครั้ง |
